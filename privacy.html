Privacy

Privacy policy

The short version: this is a static page. Everything you type — token counts, prices, your site's name and links — never leaves the browser tab.

Last updated 20 November 2026

What is collected

Nothing. The page has no account system, no sign-up, no cookies, no local storage, no analytics, no advertising script, no tracking pixel, no error reporter and no third-party embed. There is no application server to send anything to: the HTML, CSS, JavaScript and font files are the whole program.

What happens to what you type

Token counts, model prices, your budget, the site name and every link you enter for llms.txt are held in the memory of the open tab and used only to draw the numbers and the preview on the same screen. They are not saved, not synchronised and not transmitted. Closing or reloading the tab discards them.

The clipboard is written only when you press a copy button, and a file is created only when you press a download button. Both actions stay on your device.

Network requests

The page requests its own files from the address you opened it from, and nothing else. There is no CDN, no web-font service and no API call. Once the page has loaded it keeps working with the network switched off.

Outbound links — the llms.txt specification and the providers' pricing pages — open only when you click them, and those sites then apply their own policies.

Hosting

If this page is served by a static host such as GitHub Pages, the host may record standard access information (IP address, user agent, requested path) in its own logs as part of serving any website. That logging belongs to the host, happens before this page runs, and is not something the page can read, change or use.

Model prices

The built-in prices are published list prices copied from each provider's public pricing page on 20 November 2026. They are reference data, not an offer, and they are editable so you can enter your own contract rate. This page is not affiliated with OpenAI, Anthropic, Google or DeepSeek.

Children and sensitive data

The tools are aimed at developers and businesses. Please do not paste secrets — API keys, passwords, customer records — into the sample-text box; it is only there to count characters.

Changes and contact

If this policy changes, the date above changes with it. Questions can go to contact@example.com, which is a placeholder address for this build and should be replaced before the page is published under a real domain.
